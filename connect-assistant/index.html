Readerfold / Assistant connections

Readerfold MCP: connect an AI assistant to your manuscript feedback

Readerfold's Model Context Protocol (MCP) connection lets a compatible AI assistant retrieve saved manuscript feedback or request new AI readings. Readerfold connection keys control whether an assistant can only read account content or can also create manuscripts and request paid AI work.

What is the Model Context Protocol?

The Model Context Protocol (MCP) is an open standard that lets AI applications connect to external tools and data sources. Readerfold uses MCP to expose manuscript and feedback tools to an assistant authorized by the account owner. MCP documentation

What can an assistant read through Readerfold MCP?

A Readerfold read-only MCP key lets an assistant list manuscripts, retrieve manuscript passages and saved feedback, check reading progress, and view the account's credit balance. Readerfold read-only access applies across the connected account's manuscripts and does not restrict the assistant to a single chosen draft.

A Readerfold read-only key cannot create manuscripts, configure readers, or start paid AI work. Read-only access is suitable for a writer who wants to discuss existing feedback with an assistant.

Example request: “List my Readerfold manuscripts so I can choose the draft to discuss.”

What can an assistant do with reading permission?

A Readerfold MCP key with reading permission can create a manuscript from text, prepare and configure readers, estimate a reading, start a reading, and request an editorial report. Readerfold charges applicable AI work to the connected account's available credits.

Readerfold manuscript genre analysis and reader preparation can also use credits. A connected assistant should explain credit use and ask for the writer's approval before requesting paid AI work.

Which MCP clients work with Readerfold?

Readerfold supports remote MCP clients that use Streamable HTTP and accept a custom Authorization header containing a bearer key. Readerfold does not currently provide OAuth sign-in for MCP, so clients that require an OAuth connection cannot use Readerfold MCP.

A bearer key is a credential that authorizes requests from the connected assistant. Writers should store Readerfold bearer keys in the assistant's secure connection settings rather than in a conversation, shared document, or URL.

How do you connect an assistant to Readerfold?

  1. Sign in to a verified Readerfold account and open Connections.
  2. Create a named Readerfold connection key with read-only or reading permission and a 7-, 30-, or 90-day expiry.
  3. Add a remote MCP server in a compatible assistant using the server URL displayed in Readerfold Connections.
  4. Set the assistant's Authorization header to Bearer YOUR_KEY, replacing YOUR_KEY with the generated Readerfold key.
  5. Ask the assistant to list Readerfold manuscripts and choose the manuscript to discuss.

Readerfold displays the full connection key only when the key is created. Readerfold stores a hash of each connection key rather than a readable copy of the key.

Can Readerfold MCP spend more than a reading estimate?

Readerfold checks an approved estimate before starting an MCP reading or editorial report, but the approved estimate is not a hard spending cap. Actual Readerfold credit use can differ from an estimate, and manuscript analysis or reader setup can generate additional credit use.

A writer who wants an assistant to discuss saved feedback without starting paid AI work should choose a Readerfold read-only key. Readerfold connection keys cannot purchase credits or change billing settings.

Does an MCP connection make a manuscript public?

Connecting an assistant through Readerfold MCP does not publish the connected account's manuscripts on Readerfold. The connected assistant provider receives requested manuscript content and feedback and handles that content under the assistant provider's own policies.

Readerfold's training opt-outs with its AI processing providers do not govern an assistant chosen separately by the writer. The Readerfold Privacy Policy explains connected-assistant processing and manuscript handling.

What happens when a Readerfold connection key is revoked?

Revoking a Readerfold MCP key blocks new requests made with the revoked key. Readerfold jobs accepted before revocation may still finish and use account credits.

Readerfold connection keys cannot delete manuscripts, manage billing, or access another user's account. Writers can revoke individual keys from Readerfold Connections.

Do writers need MCP to use Readerfold?

Writers can use Readerfold's website to request and review manuscript feedback without configuring MCP. Readerfold MCP provides an additional way to work with the same account's manuscripts and feedback through a compatible assistant.
